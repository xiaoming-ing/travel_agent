### 01.前端怎么消费后端的SSE流式响应？
用fetch API 流式读取(response.body.getReader),不是eventSource.因为eventSource不支持自定义请求头，无法做鉴权。
- fetch发请求，拿到response.body
- const reader = response.body.getReader()获取流读取器
- while(true)循环调reader.read()
- 用textDecoder解码成字符串，累积到buffer
- 按照\n\n分割报文(SSE格式)，每段提取data:后到JSON

### 02.高德地图是怎么集成到？遇到过什么坑？
用amap-jsapi-loader动态加载高德JS API
地图绘制：
景点marker:用数字，和编号行程一致
酒店marker:用字母徽章
路径连线：AMap.polyline把景点顺序连起来

坑：景点坐标（0，0）时(LLM没填或者解析失败)，会出现一个景点在非洲
